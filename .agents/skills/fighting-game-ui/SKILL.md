# Fighting Game UI & Interaction Standards

Design guidelines for creating immersive fighting game interfaces.

## 1. Atmosphere & Visual Hierarchy
- Deep obsidian and charcoal foundation (`#04060A`, `#080B12`).
- Aggressive metallic accents and high-energy neon highlights (Crimson `#E11D48`, Electric Cyan `#0EA5E9`).
- Angular geometry, polygon corner cuts, and metallic edge bevels.
- Avoid flat SaaS cards, generic rounded corners, or pastel themes.

## 2. Main Lobby Layout
- **Left Column:** High-visibility menu actions (PLAY, FIGHTERS, TOURNAMENT, TRAINING, PROFILE, SETTINGS).
- **Center-Right:** Featured Fighter showcase with ambient idle breathing animation, elemental backdrop, and stat overview.
- **Top Bar:** Player rank, level, XP progress bar, AX Coins currency, server connectivity status.

## 3. In-Match HUD Gauges
- Slanted angular health meters with trailing damage buffer.
- Multi-segment super meter with charging particle effects.
- Central countdown timer with warning pulse when $< 10$ seconds.
- Gold metallic round-counter gems.
